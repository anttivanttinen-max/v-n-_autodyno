# VÄNÄ MOTOLAB v30 – dynolappu

Vedot-näkymä on siistitty sovitun linjan mukaiseksi:
- tumma teema
- käyrä pääosassa
- huipputeho / huippuvääntö / max RPM heti näkyvissä
- vedon asetukset kompaktilla rivillä
- teho paksulla punaisella ja vääntö ohuemmalla oranssilla
- RPM-asteikko alhaalla ja hv/Nm-asteikko vasemmalla
- valinnainen tiheä ristikko
- koko näytön käyrä, zoom, vertailu ja yhdistetty referenssi säilyvät
- v29 oppimisdatan keruu, v28 BT-laitevalinta ja GPS/RPM/vaihdekalibroinnit säilyvät
