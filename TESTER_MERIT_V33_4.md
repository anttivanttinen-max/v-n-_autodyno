# MotoLab v33.4 — Tester Merit

Build: `2026-08-17i-tester-merit`

## Periaate

Tester Merit palkitsee laadukkaasta osallistumisesta, ei viestimäärästä.

- Turha palaute, toisto tai pisteiden kalastelu ei nosta testeritasoa.
- Hyödyllinen bugiraportti, toistettava havainto, toimiva ratkaisu, laadukas testaus, yhteisöapu ja hyvä kehitysidea voivat nostaa meriittiä.
- Käyttäjää ei rangaista huonosta datasta, jos syy on laitteessa, sovelluksessa, anturissa tai muuten käyttäjästä riippumaton.
- Tekninen epäonnistuminen voidaan luokitella: user / device / app / sensor / unknown / none.
- Pisteitä ei vähennetä automaattisesti teknisen epäonnistumisen vuoksi.
- Sama palaute, ongelma tai kommentti voidaan arvioida vain kerran.
- Admin voi antaa erillisen bonusmeriitin poikkeuksellisen hyvästä ideasta tai muusta arvokkaasta panoksesta.

## Testeritasot

- 0–39: Beta Tester
- 40–64: Active Tester
- 65–84: Advanced Tester
- 85–100: Core Tester

Käyttäjälle näytetään testeritaso, ei tarkkaa pistekaavaa. Admin näkee tarkan pistemäärän, kategoriat ja pistehistorian perusteluineen.

## Merit-kategoriat

- data
- reports
- activity
- community
- reliability
- ideas

## Käyttöoikeudet

Testeritaso ei itsessään automaattisesti avaa syvempiä tai kokeellisia ominaisuuksia. Admin päättää käyttäjäkohtaisista ominaisuusoikeuksista. Tester Merit toimii päätöksenteon tukena, jotta hyödyllisimmät ja luotettavimmat testaajat voidaan kutsua uusiin testivaiheisiin.

## Tietosuoja

Tester Meritin yksityiskohtainen arviointi, pistehistoria ja perustelut ovat admin-käyttöön. Muille käyttäjille ei näytetä toisten testerien pisteitä tai arviointihistoriaa.
